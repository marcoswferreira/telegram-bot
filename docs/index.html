Telegram Bot HTTP Relay & Channel Manager

A lightweight, single-binary Rust service for sending Telegram messages and media, managing existing groups/channels via the Bot API, and provisioning new channels/supergroups via MTProto.

Download Insomnia Collection

Step-by-Step Setup

1. Create a Telegram Bot

Message @BotFather on Telegram, run /newbot, and copy your bot token.

2. Add Bot to Target Chat

Add the bot to your group, or add it as an administrator in your channel with post/edit rights.

3. Configure .env

Copy .env.example to .env and set TELEGRAM_BOT_TOKEN and API_KEY.

4. Run the Service

Start with docker compose up -d --build or run the compiled release binary directly.

Run with Docker Compose (Recommended)

cp .env.example .env
# Edit .env with your TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID, and API_KEY
docker compose up -d --build
curl http://localhost:8080/health

Run Locally from Binary / Source

cp .env.example .env
cargo run --release
# Or run the prebuilt binary:
./telegram-bot

Optional: MTProto Setup (Create Channels & Groups)

The standard Telegram Bot API cannot create new channels or groups. To enable POST /api/v1/chats/channels and POST /api/v1/chats/groups: 

# 1. Get TELEGRAM_API_ID and TELEGRAM_API_HASH from https://my.telegram.org
# 2. Set them in .env (and optionally TELEGRAM_BOT_USERNAME=@your_bot to auto-promote your bot)
# 3. Authorize your user session once interactively:
./telegram-bot --mtproto-login

# 4. Start the server normally (session is persisted in ./data/telegram.session)
docker compose up -d
